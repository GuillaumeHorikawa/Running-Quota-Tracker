Set up your tracker

Your run data is stored in a private GitHub Gist — free, no server needed, and accessible from your phone widget too.

  1. Go to github.com/settings/tokens/new
  2. Give it a name (e.g. "Running Tracker"), set expiration to No expiration
  3. Under Scopes, check gist only
  4. Click Generate token and paste it below
